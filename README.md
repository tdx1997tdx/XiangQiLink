# XiangQiLink 象棋连线助手

识别屏幕上任意象棋软件的棋盘，交给皮卡鱼（Pikafish）引擎计算，在棋盘上画出最优着法，也可以自动走子。

基于 [VinXiangQi](https://github.com/Vincentzyx/VinXiangQi) 和 [amw1933/XiangQiLink](https://github.com/amw1933/XiangQiLink) 修改，GPL-3.0 开源。

**[⬇ 下载最新版](../../releases/latest)**：解压即用，已内置皮卡鱼 2026-09-06 引擎、识别模型和开局库。

## 功能

- **自动全屏识别**：不用选窗口，屏幕上出现棋盘就识别
- **指定窗口识别**：后台截图，窗口被遮挡也能识别；内置天天象棋、JJ 象棋、雷电模拟器等方案
- **深色 / 浅色棋盘**：YOLOv5 模型，含 JJ 象棋等深色棋盘训练数据
- **自动走棋 / 观战模式**：自动点击走子，或只显示推荐着法不动鼠标
- **开局库**：内置象眼云库、徐风依旧（`.obk` 格式），可选在线云库
- **自动续盘**：一局结束自动点「再来一局」
- **日志**：识别、引擎、点击全过程记录在 `logs\`，识别失败的截图存在 `debug\`

## 快速开始

1. 从 [Releases](../../releases/latest) 下载压缩包，解压到任意目录，运行 `XiangQiLink.exe`（需要管理员权限，启动时点「是」）
2. 方案保持「**自动全屏**」，棋盘露在屏幕上、不要被本程序挡住
3. 选模式后点「**一键连线**」：
   - **自动走棋**：程序识别、计算、自动点击走子
   - **观战模式**：只在程序里的棋盘上画箭头，不动鼠标
4. 中途连线、正好轮到你走时，点「**立即出招**」

### 用指定窗口代替自动全屏

点「新建连线方案」→ 按住瞄准器 ⊕ 拖到游戏窗口上（出现红框）再松开 → 保存。之后在方案下拉框里选它即可，游戏窗口不必露在最前面。

### 引擎设置建议

| 项目 | 建议 |
|---|---|
| 线程数 | 设为 CPU 逻辑核心数（如 12 线程的 CPU 设 12） |
| 哈希表 | 内存 16GB 设 1024～2048MB |
| 思考时间 | 越长越强，按对局时限设 |
| 识别确认次数 | 有走子动画的平台（如天天象棋）设 2～3，避免识别到动画中途的画面；在「识别高级设置」里 |

详细说明见 [使用说明.md](使用说明.md)。

## 运行环境

- Windows 10 / 11（64 位）
- .NET Framework 4.8（系统自带）
- 支持 AVX2 的 CPU 运行皮卡鱼最快（程序会自动选择最优指令集）

## 从源码编译

源码在 `src/VinXiangQi/`（C# WinForms，.NET Framework 4.8，x86）。

- **Visual Studio 2019+**：打开 `VinXiangQi.csproj`，还原 NuGet 包，Release 编译
- **Linux + Mono**：`xbuild src/VinXiangQi/VinXiangQi.csproj /p:Configuration=Release`

编译出的 exe 需要放在完整的发布目录里运行（模型、引擎、开局库等资源见 [RESOURCES.md](RESOURCES.md)），最简单的做法是下载 Release 压缩包，替换其中的 `XiangQiLink.exe`。
